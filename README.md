# Smart Expense Tracker — Phase 1

Beginner-friendly Flask project setup.

## Run

1. Create and activate a virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Start Flask:

```bash
python app.py
```

4. Open:

http://127.0.0.1:5000

This ZIP contains Phase 1 only. Database, authentication, transactions, budgets, reports, and the final UI will be added in later phases.
